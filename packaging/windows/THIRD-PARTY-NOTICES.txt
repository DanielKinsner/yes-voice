YesVox v1.0 Third-Party Notices
================================

This notice file is displayed by the unsigned Windows setup recipe and is also
installed next to YesVox. It covers package-time model-weight candidates tracked
in licenses/model-weights.tsv. The exact shipped neural artifacts are staged
outside git and must be recorded with bundled SHA-256 values before a release
package is cut.

Package-time release blockers
-----------------------------

- Stage release binaries in YESVOX_BIN_DIR.
- Stage ONNX Runtime or other required runtime files in YESVOX_RUNTIME_BUNDLE_DIR.
- Stage the exact approved model payloads in YESVOX_MODEL_BUNDLE_DIR.
- Update licenses/model-weights.tsv from candidate to bundled only for files
  that are actually included in the setup package.
- Keep this file synchronized with every non-comment row in
  licenses/model-weights.tsv.
